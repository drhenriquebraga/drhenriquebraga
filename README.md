# Henrique Braga

I'm a radiation oncologist in Rio de Janeiro. Since 2014, I've been building tools for the work around a radiotherapy service: medical records, positioning photographs, documents and medical imaging.

## Projects

- **[Local Suite](https://github.com/drhenriquebraga/local-suite)** — Windows applications for medical imaging, contours, 3D reconstructions and DICOM preparation.
- **[PhotoID RT](https://github.com/drhenriquebraga/photoid-rt)** — positioning photographs and Time-Out sheets on Android tablets.
- **[POP de Elite](https://github.com/drhenriquebraga/Pop-de-Elite)** — drafts of quality documents for professional review.
- **[Workstation Kit](https://github.com/drhenriquebraga/workstation-kit)** — tools for checking and maintaining a Windows workstation.

Other public repositories: [3D Printed Bolus](https://github.com/drhenriquebraga/3d-printed-bolus), [ContourLab](https://github.com/drhenriquebraga/contourlab), [DicomBridge](https://github.com/drhenriquebraga/dicom-bridge), [Elastic RT](https://github.com/drhenriquebraga/elastic-rt), [Neuro RT](https://github.com/drhenriquebraga/neuro-rt), [Nidus RT](https://github.com/drhenriquebraga/nidus-rt), [Recon 3D](https://github.com/drhenriquebraga/recon-3d) and [Lung RT](https://github.com/drhenriquebraga/lung-rt).

**In development:** Orbital Hospital, an educational virtual hospital. Virtual LINAC is its radiotherapy quest line.

I share projects with Lucas Brito and other builders through [radioterapia.ai](https://radioterapia.ai).
